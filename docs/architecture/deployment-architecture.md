# Deployment Architecture

## Overview

Industrial Nexus is deployed on **Render** as a set of managed services: one API server, three Next.js PWAs, and a managed Redis instance. The monorepo is built with `npm` workspaces and Turbo pipelines, and each service is built independently.

## Render Services (`render.yaml`)

| Service | Name | Type | Build Command | Start Command |
|---------|------|------|---------------|---------------|
| API | `industrial-nexus-api` | Web (Node) | `npm install && cd apps/backend && npm install && npx prisma generate && npx prisma migrate deploy && npm run build && npm run seed` | `cd apps/backend && node dist/src/main` |
| Admin PWA | `industrial-nexus-admin` | Web (Node) | `npm install && cd apps/admin-pwa && npm install && rm -rf .next && npm run build` | `cd apps/admin-pwa && npm run start` |
| Client PWA | `industrial-nexus-client` | Web (Node) | `npm install && cd apps/client-pwa && npm install && rm -rf .next && npm run build` | `cd apps/client-pwa && npm run start` |
| Driver PWA | `industrial-nexus-driver` | Web (Node) | `npm install && cd apps/driver-pwa && npm install && rm -rf .next && npm run build` | `cd apps/driver-pwa && npm run start` |
| Redis | `industrial-nexus-redis` | Redis | Managed | Managed |

## Environment Variables

### Backend

- `DATABASE_URL` — PostgreSQL connection string.
- `REDIS_ENABLED` — `true` in production, `false` for local fallback.
- `REDIS_URL` — Redis connection string (sourced from Render Redis service).
- `JWT_SECRET`, `JWT_REFRESH_SECRET` — auto-generated by Render.
- `NODE_ENV` — `production`.
- `CORS_ORIGIN` — comma-separated allowed PWA origins.

### PWAs

- `NEXT_PUBLIC_API_URL` — backend REST API URL.
- `NEXT_PUBLIC_WS_URL` — backend WebSocket URL.
- `NEXT_PUBLIC_MAP_TILE_STYLE_URL` — optional custom OSM tile style.
- `NEXT_IGNORE_INCORRECT_LOCKFILE` — workaround for offline lockfile patching.

## Local Development

```bash
npm install
npm run dev:backend   # port 3001
npm run dev:admin     # port 3000
npm run dev:client    # port 3003
npm run dev:driver     # port 3002
```

The root `turbo.json` defines `build` and `dev` pipelines with workspace dependencies. Builds produce `.next/` for PWAs and `dist/` for the backend.

## Database Migrations

- Local: `npm run db:migrate` and `npm run db:seed`.
- Production: `npx prisma migrate deploy` runs during the Render build step; `npm run seed` runs after build.

## Build Outputs

- Backend: `apps/backend/dist/`
- PWAs: `apps/<pwa>/.next/`

## Scalability Considerations

- Render web services can be scaled vertically and horizontally; Redis and PostgreSQL are managed and independently scalable.
- The backend is stateless except for WebSocket connections; horizontal scaling requires sticky sessions or externalizing session state (currently managed via DB).
- Uploaded files are stored on local filesystem; moving to object storage (e.g., S3, Cloudflare R2) is recommended for multi-instance deployments.
