## Typography Standard (Mandatory)

Use the following typography throughout the Industrial Nexus application.

### Primary UI Font
- Font Family: Inter, sans-serif
- Use for:
  - Headings
  - Body text
  - Buttons
  - Forms
  - Navigation
  - Tables
  - Cards
  - Modals
  - Dashboards

### Monospace Font
- Font Family: JetBrains Mono, monospace
- Use for:
  - Numbers
  - Tracking IDs
  - Order IDs
  - Vehicle IDs
  - Waybill Numbers
  - Status metrics
  - Analytics
  - Dates & timestamps where appropriate
  - Logs
  - Code snippets
  - GPS coordinates

Typography should resemble premium SaaS products such as Windsurf, Linear, and Vercel.

Do not use any other font unless explicitly instructed.
